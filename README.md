# easypos-ks-legacy-builds

easyPos Kosova legacy desktop releases, for computers that the current app no longer supports:

- **Windows 7 SP1, 8 and 8.1, and 32-bit Windows**: one installer for 32-bit and 64-bit systems.
- **macOS 10.13 High Sierra to 12 Monterey**: one universal DMG for Intel and Apple silicon Macs.

Windows 10 and 11 (64-bit) and macOS 13 Ventura or later use the current app: <https://easypos-ks.com/download>.

The legacy app updates itself from this repository's latest release.
